# Omarchy Web

A browser-based take on the experience of using
[Omarchy](https://omarchy.org) — DHH/Basecamp's opinionated Arch Linux +
Hyprland desktop setup. Not Linux in the browser: the same *feel* — a
keyboard-driven tiling desktop with a top bar, an app launcher,
workspaces, themeable chrome, and a small curated set of apps (terminal,
editor, file manager, media players, calculator, …) reimplemented with
plain web technologies. No framework, no bundler, no build step — open
`index.html` in a browser and it works, even from `file://`.

## Themes

All 22 themes are ported from the theme folders of the upstream
[Omarchy repo](https://github.com/basecamp/omarchy) (quattro branch) —
palettes and wallpapers verbatim. Credit goes to the Omarchy authors and
community theme contributors, and to the original palette projects the
themes are based on, including:

- [Catppuccin](https://github.com/catppuccin) (and Catppuccin Latte)
- [Everforest](https://github.com/sainnhe/everforest)
- [Flexoki](https://stephango.com/flexoki) by Steph Ango
- [Gruvbox](https://github.com/morhetz/gruvbox)
- [Kanagawa](https://github.com/rebelot/kanagawa.nvim)
- [Nord](https://www.nordtheme.com/)
- [Rosé Pine](https://rosepinetheme.com/)
- [Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme) — the default theme

Plus the Omarchy originals and community themes: Ethereal, Hackerman,
Last Horizon, Lumon, Lupine, Matte Black, Miasma, Osaka Jade, Retro-82,
Ristretto, Solitude, Vantablack, and White.
